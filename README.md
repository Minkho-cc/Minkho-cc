# Hi, I'm Daniel :wave:

**Here for tech for good. Mostly after 6 pm.**

I work at the intersection of society, culture, politics and tech has always been part of the picture. Not as my job, but as a curiosity that simply grows.

## How I got here

**:bar_chart: Open data.** It all started with numbers anyone can look up: bike traffic counts, road accident statistics. I wanted to know what stories they tell, so I started visualizing them.

**:speech_balloon: Communities.** Next, I stumbled into Telegram and discovered how people rally around shared information and a common purpose, supporting and mobilizing each other. One message alone means little, but when thousands contribute, a loose group turns into a community with real collective power.

**:tram: [FreiFahren](https://github.com/FreiFahren).** At some point the question became: what can you actually *build* from publicly available data, something that's genuinely useful in people's everyday lives? When I saw the very same idea already running in Berlin, I teamed up with the developers there. I've been part of FreiFahren ever since, focusing on Leipzig.

## What drives me

Curiosity, plain and simple. I'm not a software developer, yet. I'm someone starting to discover a whole new world, fascinated by how data, code and communities can create change together: in the neighborhood, in the city, in society.

- :chart_with_upwards_trend: Making open data visible and easy to understand
